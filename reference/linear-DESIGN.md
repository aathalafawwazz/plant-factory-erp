# Design System: Linear

## 1. Visual Theme & Atmosphere

The interface exudes professional confidence through its sophisticated dark theme, creating an environment that feels both modern and focused. The deep charcoal background provides a calming foundation while vibrant blue accents inject energy and guide attention to key interactions. This creates a workspace that feels serious yet approachable, designed for sustained productivity.

The design uses subtle layering with the main content area appearing to float above the dark background. Minimal shadows and clean borders create gentle separation between interface elements without heavy visual weight.

Clean geometric forms dominate with subtle rounded corners on interactive elements. Icons maintain consistent stroke weights and sizing, while the overall aesthetic favors crisp edges and precise alignment.

## 4. Component Stylings

* **primary-button:** White background button with dark text, rounded corners, used for primary actions like 'Sign up'
* **navigation-link:** Clean text links in the header navigation with subtle hover states and consistent spacing
* **sidebar-nav-item:** Left sidebar navigation items with icons, subtle backgrounds, and organized hierarchy for workspace navigation
* **issue-card:** Content cards with dark backgrounds, subtle borders, and organized information display for issue tracking
* **status-indicator:** Colored status badges and indicators using brand accent colors to show progress and priority levels
* **hero-section:** Large typography treatment with generous whitespace and prominent call-to-action positioning

## 5. Layout Principles

Generous whitespace creates breathing room throughout the interface, with consistent vertical rhythm and well-defined content areas. The layout follows a clear grid system with ample margins and structured information hierarchy.
